⏺ All 56 tests pass now.

  The failing test was test_different_chinese_names_get_different_ids. slug() in
  names.py strips non-ASCII characters, so every Chinese name came out as
  "unnamed" and two designers could end up with the same id.

  My fix: if nothing survives the ASCII conversion but the name still has real
  letters, slug() returns n- plus a short SHA-1 hash of the name (for example
  n-1a2b3c4d5e). The same name always gets the same id, and different names get
  different ones. Empty or punctuation-only input such as "" or "!!!" still
  returns "unnamed", as test_slug_of_nothing_usable_is_unnamed expects.

  Chinese designers now get hash-style ids rather than readable ones. I chose
  that over transliterating to pinyin, which would need a new dependency. Ids
  already stored in the database as "unnamed" are not migrated.

  pytest wasn't installed in .venv, so I installed it there to run the suite. I
  haven't committed anything.
