⏺ The suite passes now: 56 tests, up from 55 passing and 1 failing.

  The failing test was test_different_chinese_names_get_different_ids. slug() in
  names.py drops all non-ASCII characters, so a name written only in Chinese
  became an empty string and fell back to "unnamed". Two different people
  therefore got the same id.

  The fix is in names.py. The ASCII path is unchanged, so the English-name ids
  in designers.csv still reproduce. When no ASCII letters or digits remain but
  the name contains real characters, slug() now returns u- plus a 12-character
  SHA-1 prefix of the name. Different names get different ids, and the same name
  always gets the same one. Names with no letters or digits, like "!!!", still
  return "unnamed". The change uses only the standard library, so the CI
  workflow's pytest-only install still works.
